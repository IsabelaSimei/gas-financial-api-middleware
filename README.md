# gas-financial-api-middleware
Google Apps Script - Webhook Middleware para API Financeira/Chatbot

Middleware construído em Google Apps Script que atua como ponte entre chatbots e endpoints de uma API financeira restrita. Processa chamadas POST, autentica via Basic Auth, roteia requisições dinâmicas (Validação de Usuário, Informações de Crédito, Refinanciamento e Morosidade) e grava logs de respostas diretamente no Google Sheets.
